# Zanevka Newsbot

Приложение для автоматической подготовки и публикации новостей из электронной почты на WordPress-сайте zanevkaorg.ru.

## Возможности

- Получение и пакетная обработка входящих писем.
- Извлечение DOCX, изображений и ссылок VK.
- Автоматическое сопоставление материалов.
- Проверка полноты партии и однократная отсрочка публикации.
- Публикация новостей в WordPress.
- WebUI для управления запуском, настройками и просмотра журналов.

## Архитектура

Приложение состоит из независимого Python-конвейера и WebUI на Flask/Waitress.

**Основной поток:** IMAP → подготовка партии → проверка полноты → публикация или отсрочка.

## Эксплуатация

- Ubuntu 24.04 LTS, RELEASE.
- Python 3.12, Pandoc, Caddy.
- Автоматический запуск через cron каждые два часа.
- WebUI работает как служба systemd.
