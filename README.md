# Zanevka Newsbot

## Цель проекта

**Zanevka Newsbot** — проект автоматической подготовки и публикации новостей из входящих писем на WordPress-сайте `zanevkaorg.ru`. Обработка выполняется Python-модулями; каталог `webui/` содержит веб-интерфейс для будущего управления программой и просмотра журнала.

Основной pipeline:

```text
почта -> .eml -> парсинг текста/ссылок/изображений -> VK -> подготовка контента -> WordPress -> cleanup
```

Ошибка при обработке одной новости не должна останавливать обработку следующих писем. Временные `.eml` и извлечённые изображения должны очищаться после каждой итерации, в том числе при ошибке.

## Python Newsbot: основные модули

- `main.py` — orchestration: связывает этапы обработки.
- `eml_parser.py` / `eml_links.py` — письмо, вложения и ссылки.
- `news_parser.py` — формирование структуры новости.
- `image_manager.py` — изображения и загрузка медиа.
- `vk_video.py` — данные и preview VK.
- `wordpress.py` — взаимодействие с WordPress.
- `config.py` — локальная конфигурация; секреты не должны попадать в Git.

## Python Newsbot: основные директории

- `probe/` — директория диагностических и тестовых скриптов для Python Newsbot.
- `downloaded_eml/` и `extracted_images/` — директории временных данных обработки.

Подробные границы ответственности модулей описаны в `gpt_context/ARCHITECTURE.md`.

## WebUI

- `webui/index.html` — разметка интерфейса с журналом, элементами управления и вкладками настроек.
- `webui/index_files/` — JavaScript, CSS и SVG-ресурсы.
- `webui/README.md` — описание функций и структуры WebUI.
- `webui/AGENTS.md` — специальные правила работы AI с интерфейсом.

**Текущее состояние:** WebUI — самостоятельный статический макет без связи с Python Newsbot, предназначенный для проверки дизайна и демонстрации интерфейса. Кнопка запуска воспроизводит демонстрационные сообщения, а настройки макета (кроме секретных полей) сохраняются в браузере. Настоящее управление ботом и получение его журнала ещё не реализованы.

## Разработка

GitHub — canonical repository проекта. Перед изменением кода следует ориентироваться на актуальное состояние репозитория, а не на старый контекст чатов.

Рабочая среда — Windows 10 / Python 3.13. Проект развивается небольшими проверяемыми изменениями.

Целевые ОС — Windows 10, Debian Linux и FreeBSD с единой кодовой базой. Совместимость с Unix пока требует тестирования. Периодический запуск Newsbot планируется через cron на Unix (раз в 2 часа). WebUI и будущая связка с Python также должны работать на целевых платформах; интеграция и проверка на Unix пока впереди.
