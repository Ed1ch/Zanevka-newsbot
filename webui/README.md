# Zanevka Newsbot — WebUI

## Назначение и статус

`webui/` — статический веб-интерфейс Zanevka Newsbot на HTML, CSS и JavaScript. Сейчас это **самостоятельный интерактивный макет**, не подключённый к Python newsbot.

Интерфейс показывает журнал обработки, настройки и элементы управления, но не выполняет `main.py`, не читает реальные логи и не меняет `config.py` либо cron. Для будущей интеграции выбран `webui_server.py` на Flask/Waitress: авторизованный API и SSE из файлов журналов. План ещё не реализован; решения от 2026-10-22 описаны в [DECISIONS.md](../gpt_context/DECISIONS.md).

## Структура

- `index.html` — разметка страницы, панели настроек, полей и журнала.
- `index_files/script.js` — управление состоянием интерфейса, вкладками, журналом, формой и демонстрационным запуском.
- `index_files/theme_switcher.js` — переключение цветовых тем.
- `index_files/style.css` — основные стили.
- `index_files/settings_window.css` — плавающее окно настроек.
- `index_files/style_log_fades.css`, `switch_style.css`, `log_controls_colors.css` — специализированные стили.
- `index_files/themes.css` — подключённые цветовые темы; другие файлы `themes_*.css` присутствуют как дополнительные варианты.
- `index_files/*.svg` — логотип и иконки.

При поиске причины поведения элемента проверяй также связанный HTML и все влияющие на него стили и обработчики.

## Текущее поведение

- **Журнал:** демонстрационные записи; фильтр по всем сообщениям, предупреждениям и ошибкам, очистка и экспорт. Поддерживаются ручная прокрутка, автоследование за новыми сообщениями и масштаб Ctrl + колесо мыши.
- **Запуск:** кнопка «Запустить сейчас» просто имитирует запуск скрипта, показывая тестовые записи по таймеру, а не запускает сам Python newsbot.
- **Статус и расписание:** переключатель «Запуск по расписанию» меняет только состояние макета. Вкладка «CRON» показывает демонстрационные параметры интервала и часового пояса; реальный cron или другой планировщик не изменяются.
- **Настройки:** вкладки «Почта», «WordPress», «API VK», «CRON». Панель по умолчанию свёрнута, открывается по выбору вкладки; поддерживает закрытие, перемещение за активную вкладку и изменение размера. Двойной щелчок по активной вкладке сворачивает панель.
- **Цветовые темы:** переключаются нажатием на заголовок Zanevka Newsbot; настройка темы сохраняется в браузере.
- **Кнопка сохранения настроек** пока не записывает изменения в `config.py`, а сохраняет их только в `localStorage` текущего браузера.

## Хранение настроек и безопасность

Кнопка сохранения записывает **несекретные** значения формы в `localStorage` текущего браузера. Поля паролей и токенов исключены из сохранения. Значения не передаются Python и не являются рабочей конфигурацией бота.

Не помещай реальные пароли, токены или данные доступа в исходники, демоданные, Git либо браузерное хранилище. Согласованный план интеграции предусматривает одного администратора, серверный хеш пароля, сессионную cookie и CSRF-защиту. Рабочие настройки будут читаться и сохраняться через API в `config.py`; секреты не возвращаются в форму, пустое секретное поле сохраняет прежнее значение. Эти функции пока отсутствуют в макете.

## Проверка

Открой `webui/index.html` в браузере (либо через локальный статический сервер). Проверь журнал, вкладки, окно настроек, темы и демонстрационный запуск. Для работы текущего макета Python не нужен.

Работающий на GitHub Pages статический макет не означает наличие запущенного Python backend.

Правила изменений webui см. в `webui/AGENTS.md`; общие инструкции и архитектуру всего проекта — в корневом `AGENTS.md` и `gpt_context/ARCHITECTURE.md`.
