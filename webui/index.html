Доступ к API

Работа с материалами

Newsbot извлекает из письма ссылки на VK и обрабатывает связанные тексты, изображения и видео.

Вложенные attachments также учитываются при разборе.
Ошибка одной новости не останавливает обработку остальных писем.

Расписание

0 */2 * * *
Запуск каждые 2 часа, в начале часа.

Управление автозапуском

Переключатель «Запуск по расписанию» вверху отключает следующие плановые запуски. Текущая обработка продолжает работу.

Unix: управление через файл .newsbot.disabled.
Windows: режим Windows/manual.

В этом макете переключается только демонстрационный статус.
